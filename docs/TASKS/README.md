## Guidelines for Authoring New Task Records

1. Copy the standard template from [../templates/TASK_TEMPLATE.md](../templates/TASK_TEMPLATE.md).
2. Name the file with the ISO date prefix: `YYYY-MM-DD-[task-slug].md`.
3. Fill out all sections: Problem Statement, Requirements, Implementation, Files Changed, State Flow, Testing, Limitations, and Acceptance Criteria.
4. Record exact verification commands and outputs.
5. Add the new entry to this index and update [../DEVELOPMENT_LOG.md](../DEVELOPMENT_LOG.md) and [../CHANGELOG.md](../CHANGELOG.md).
